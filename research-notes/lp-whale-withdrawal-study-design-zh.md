# LP 大户撤资行为研究方案（待选币）

更新时间：2026-09-02

## 1. 研究目的

这项研究不再把所有 LP 混在一起，也不把“撤质押”直接当成“资金离场”。研究对象是近期在池内控制较大有效流动性份额的 LP，重点回答：

- 大户通常在什么市场状态下开始撤资；
- 一轮撤资持续多久；
- 是一次撤完还是拆成多次；
- 如果拆单，是更接近按时间执行，还是在价格变化后继续撤；
- 撤出后是持币、卖出、重新质押，还是换区间重新做市；
- 撤资后池内深度、滑点、成交量、价格和波动发生了什么变化；
- 这些行为能否形成可复核的风险提示或调仓参考。

这是一项行为与风险信号研究，不预先声称大户撤资会造成价格下跌，也不把同期变化直接解释为因果关系。

## 2. 研究对象如何确定

### 2.1 大户份额

在每轮撤资开始前计算：

```text
大户份额 S = 该实际控制者当前有效流动性 / 池子当前总有效流动性
```

Uniswap V3 只统计当前价格所在区间内能实际参与成交的流动性。同一控制者的多个 LP NFT 合并；NFT 质押后，需要通过质押记录追溯实际控制者，不能把质押合约当成大户本人。

正式分层：

| S | 研究标签 |
|---:|---|
| `>= 10%` | 核心大户 |
| `5%–10%` | LP 大户 |
| `1%–5%` | 较大 LP，只作对照 |
| `< 1%` | 普通 LP，不做完整地址追踪 |

主要研究样本使用 `S >= 5%`。同时标记每个历史时点份额最高 5% 的“池内头部 LP”，但实际份额不足 5% 时不称为大户。正式结果必须保留准确份额，不能只显示“大户/非大户”。

为避免结论被单一门槛决定，大户门槛还要用 `3% / 5% / 10%` 分别重算。

### 2.2 撤资对池子的影响

```text
池子影响 E = 本轮实际减少的有效流动性 / 撤资前池子总有效流动性
自身撤出比例 R = 本轮撤掉的流动性 / 该控制者撤资前的流动性
```

| 指标 | 判断标准 |
|---|---|
| `E >= 5%` | 重大撤资 |
| `1% <= E < 5%` | 有明显池内影响的撤资 |
| `E < 1%` | 小额调整，通常不进入主要风险事件 |
| `R < 20%` | 小幅调仓 |
| `20% <= R < 80%` | 部分撤资 |
| `R >= 80%` | 接近清仓 |

主要事件同时要求：撤资前 `S >= 5%`、本轮 `E >= 1%`、链上确实发生减少流动性，并且没有很快把大部分流动性重新加回。

稳健性检查使用：

- 大户门槛：`3% / 5% / 10%`；
- 池子影响门槛：`0.5% / 1% / 2%`；
- 接近清仓门槛：`75% / 80% / 90%`。

如果换一组合理门槛后结论消失，结果必须标记为“对定义敏感”，不能当作稳定风险信号。

## 3. 完整行为链

每个候选大户需要按顺序还原：

```text
增加流动性
→ 获得或控制 LP NFT
→ 是否质押到奖励合约
→ 撤质押
→ 是否 DecreaseLiquidity
→ 是否 Collect
→ 是否重新加仓、换区间或重新质押
→ 取回的代币是否进入换币、路由器、交易所或其他转账路径
```

关键解释：

- 仅撤质押：流动性仍可能留在池内，不算撤资；
- `DecreaseLiquidity`：池内流动性真正减少；
- `Collect`：把本金或手续费取回钱包，本身不能单独判断卖出；
- 撤出后很快重新建立仓位：优先认定为换区间或重新配置；
- 撤出后进入卖出路径：才可能产生更直接的价格压力。

## 4. 如何识别一轮拆单

不固定使用 12 小时之类的统一分界。先用行为确定边界，再让每个池子的实际间隔分布决定时间边界。

### 4.1 行为边界优先

可能属于同一轮的操作应满足：

- 同一实际控制者；
- 同一池子；
- 连续操作方向都是减少流动性；
- 中间没有明显重新加仓或重新质押；
- NFT 没有转给新的独立所有者；
- 没有完成一次明确的换区间并重新建仓。

出现重新加仓、重新质押、建立新范围或所有权改变时，优先结束上一轮撤资。

### 4.2 池子自己的时间边界

对每个池子统计连续减仓间隔。如果短间隔操作和长期停顿之间存在明显断层，用该断层划分一轮撤资。活跃池可能是几十分钟，低频池可能是一两天。

如果样本不足，分别用 `1小时 / 6小时 / 24小时 / 72小时` 重算。结果随窗口变化很大时，标记为“不稳定”，不强行声称存在固定拆单周期。

### 4.3 时间拆单与价格拆单

- 时间拆单：相邻操作的时间间隔较规律，而操作时的价格变化没有明显规律；
- 价格拆单：操作更集中在相似的标准化价格变化之后；
- 混合型：时间和价格条件都有关；
- 无明显规律：数据不足或行为不能归类；
- 换区间：重新建仓而非永久离场。

不同币的波动差异很大，因此价格条件使用“价格变化 / 该池近期正常波动”，不使用统一的绝对涨跌幅。

## 5. 双时间尺度

### 5.1 现实时间：服务实际风控

统一报告撤资后的：

- 1 小时；
- 6 小时；
- 24 小时；
- 3 天；
- 7 天。

这些窗口回答“看到信号后多快需要行动”，不用于定义不同池子的自然反应速度。

### 5.2 相对市场时间：服务跨池比较

先用撤资前最近 30 个完整日计算：

```text
正常日交易笔数 = 前 30 日 Swap 总笔数 / 30
正常日成交量 = 前 30 日成交量 / 30
```

然后观察撤资后累计市场活动达到近期正常一天活动的：

- `0.25x`；
- `1.0x`；
- `3.0x`。

成交量是主要尺度，交易笔数是辅助尺度。固定的“25 / 100 / 500 笔 Swap”不再作为主要研究窗口。

还要计算：

```text
池子换手压力 = 撤资后累计成交量 / 撤资前池内有效流动性价值
```

它用于判断撤资后的交易需求相对于剩余流动性是否过高。

### 5.3 防误导展示规则

不能只写“成交量 300%”。统一写成：

> 撤资后累计成交量达到事件前 30 日平均日成交量的 3.0 倍。

每个观察点同时展示：

- 活动尺度；
- 基准日均成交量；
- 撤资后累计成交量；
- 达到该尺度的实际耗时；
- 期间 Swap 数量；
- 最大单笔交易占比。

`3.0x` 表示累计发生了相当于三个正常交易日的成交量，不表示成交量“上涨 300%”，也不是池子历史总成交量的 300%。如果一笔大额交易主导结果，要明确标记；如果 7 天内没有达到某个尺度，显示“7 天内未达到”，不能人为延长窗口。

基准还要用最近 `14 / 30 / 60` 日重算。低活跃池分母过小或结果对基准期敏感时，需要标记“相对比例不稳定”。

## 6. 近期数据规则

- 研究终点使用运行时 RPC 可取得的最新稳定区块；
- 主要研究窗口为最近 90 天；
- 最近 30 天单独给出更贴近当前市场的结果；
- 90 天样本不足时可以扩展到最近 180 天；
- 最长不超过 365 天，几年前的活跃周期不进入主要结论；
- 为还原 NFT 来源或质押身份，可以读取更早的创建/转移记录，但旧事件只用于身份初始化，不作为近期市场样本。

如果最近 180 天没有足够的大户撤资事件，停止该币的完整分析并优先换币，不为了凑结论回到几年前。

## 7. 第一阶段数据和交付物

选币后先做轻量可行性检查，不直接投入完整扫描：

1. 确认近期主要池和协议版本；
2. 检查最近 90 天 Swap、减少流动性及 LP NFT 事件数量；
3. 确认 Position Manager 和可能的质押合约能否追踪；
4. 输出池内份额分布和连续撤资间隔分布；
5. 判断是否存在足够的 `S >= 5%`、`E >= 1%` 候选事件；
6. 若样本可用，再运行完整行为链研究。

完整分析完成后生成一份已执行的 `.ipynb`，保存图表、表格、必要的紧凑 CSV、白话结论和限制，交给人工审阅。遇到需要改变门槛、扩大时间范围、加入新协议或解释主体归属的问题时，先停止并由研究负责人决定。
